Destaque para o cliente: Red Bull lidera em frequência de notas (28) mesmo estando presente em só 2 dos 22 PDVs mapeados — ou seja, a marca com maior giro relativo é também a com menor cobertura. Esse é o argumento mais direto para justificar expansão de distribuição.

Importante para a proposta comercial: este bloco deve ser vendido como "frequência de reposição/venda", nunca como "volume vendido" — a fonte SEFAZ/NFC-e pública não expõe quantidade, apenas ocorrência de nota fiscal. Com histórico maior (semanas/meses), este indicador passa a revelar sazonalidade e dias de pico com boa confiabilidade.
